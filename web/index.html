HOW TO EXPERIMENT

Bring all the context.

Try the valid sample first, then load the script rejection. Edit a field and run again. The selected-lock sample demonstrates a script hash selector, which is different from a code hash.

What runs here?

The repository’s createWorkerVerifier calls the real WASM engine. Each run gets a fresh Worker, terminated on completion, cancellation or a 30-second timeout. Input stays in memory and is not uploaded or saved by this page.

What do you supply?

A transaction, resolved cells, headers and extensions, origin metadata, consensus parameters and verification phase. The lab does not infer network configuration or fetch missing chain data. See the request schema and verification boundaries.
